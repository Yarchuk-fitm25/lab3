# ЛБ №3: Реалізація обробки виключень, модульності та документації в проектах Python

## Структура проєкту

```text
лб 3/
├── config_manager/          # Основний модуль пакета
│   ├── __init__.py          # Ініціалізація пакета
│   ├── __main__.py          # Точка входу для запуску
│   ├── models/              # Моделі даних та логіка
│   └── exceptions/          # Кастомні винятки (кастомні помилки)
├── .gitignore               # Файл ігнорування системних файлів Git
├── requirements.txt         # Список залежностей
└── README.md                # Документація проєкту
```
## Вимоги
Python: 3.9+
Залежності: Зовнішні бібліотеки відсутні (використовується стандартна бібліотека Python)

## Інструкція із запуску
Запуск проєкту здійснюється з кореневої директорії:
``` python -m config_manager ```
